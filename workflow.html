Daily Sales Report Workflow

How a raw export becomes the daily KDC sales report: one report per day, built from the files dropped into Input. The workbook in Main is only changed when you answer Yes at the end. See also the flow diagram.

Built working today   Planned not built yet   You done by a person

The flow

1

Drop the raw export You

Save the file exactly as it comes out of the sales system. No editing needed.

Folder: Input
2

Start the run You

Double-click Run.bat. Everything from step 3 to step 7 happens on its own.

3

Read the file Built

  • Finds the header row, even with title lines above it or a header spread over two rows.
  • Matches columns by header name, so the column order in the export does not matter.
  • Recognises each export by its columns, not its file name, and writes a checklist of the 15 parts a full day brings (sale, order and stock for KDC, Dealer, Geely, BMW and MBS) with an alert for every part that is missing.
4

Fix the data Built

  • Removes rows with no frame number (the total row) and frame numbers repeated in the export.
  • Renames models to the name the report counts: Hyundai TUCSON becomes NEW TUCSON.
  • Splits the rows by brand into the sheet each one belongs to (see the table below).
Result: adjust\Sales adjusted <time>.xlsx, with a sheet of removed rows and a sheet of changes.
5

Apply to a copy of the main workbook Built

  • Adds only cars whose frame number is not in the workbook yet.
  • Cars already there are left as they are; any difference is written to the QC report.
  • Copies cell formats and the lookup formulas down to the new rows.
  • Stops without writing if the export does not look like the sheet.
6

Recalculate and check Built

  • Excel recalculates every report sheet.
  • Key totals are recorded before and after.
  • Flags: duplicate cars, a showroom or model the report has no row for, and month totals that disagree between sheets.
7

Save the results Built

Each run gets its own numbered folder inside the day's folder.

Folder: output\<date>\<run number> holding the workbook, the report pictures and the QC report.
8

QC and release You

Read the QC report, check the workbook and pictures, then send the report.

9

Answer the two questions You

  • Replace the workbook in Main with this output? Yes makes the output the main file for the next day; the old one is kept in Main\previous. No leaves Main as it is.
  • Delete the export files that were used? Yes sends them to the Recycle Bin so Input is empty for the next day. Files the script did not recognise stay.

The boxes wait, so you can finish the QC first. No is the default for both.

Folders

Input

Raw exports from the system, as received.

adjust

The fixed version of each export, before it touches the main workbook.

Main

The main report workbook. Exactly one file. Only changed when you answer Yes to replacing it.

output

One folder per day, one numbered folder per run, for QC.

Roll the workbook over to the next month: freeze last month's totals, move the day columns, empty the sales sheets. For now the run only alerts when the export's month differs from the workbook's.
