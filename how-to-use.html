วิธีใช้ Daily Sales Report

คู่มือการทำรายงานยอดขายรถประจำวัน (KDC SPDR) ด้วยโปรแกรมในโฟลเดอร์ D:\Automation งานประจำวันมีแค่ 4 อย่าง: วางไฟล์ export, ดับเบิลคลิก Run.bat, ตรวจ QC, ตอบคำถาม 2 ข้อ ถ้าอยากรู้ว่าโปรแกรมทำอะไรข้างในทีละขั้น ดูที่ workflow.html

ติดตั้งครั้งแรก ขั้นตอนประจำวัน ไฟล์ที่ต้องวาง ผลลัพธ์ที่ได้ อ่าน QC report สิ่งที่โปรแกรมทำกับข้อมูล แก้ปัญหา ข้อจำกัด ทดลองรัน

ติดตั้งครั้งแรก (ทำครั้งเดียวต่อเครื่อง)

1

เครื่องต้องมี Microsoft Excel

โปรแกรมใช้ Excel คำนวณสูตรและถ่ายรูปรายงาน ตัว Setup ติดตั้ง Excel ให้ไม่ได้

2

ดับเบิลคลิก Setup.bat

ต้องต่ออินเทอร์เน็ต โปรแกรมจะติดตั้ง Python กับ library ที่ต้องใช้ และสร้างโฟลเดอร์ Input, adjust, Main, output ให้

เสร็จแล้วต้องขึ้นว่า Setup finished. Everything is ready.

3

วางไฟล์รายงานหลักไว้ใน Main

ใน Main ต้องมีไฟล์ workbook ไฟล์เดียวเท่านั้น (โฟลเดอร์ย่อย Main\previous ไม่นับ) และต้องเป็นไฟล์ของเดือนที่กำลังทำรายงาน

ขั้นตอนประจำวัน

1

วางไฟล์ export ลงใน Input

วางตามที่ดาวน์โหลดมาจากระบบได้เลย ไม่ต้องแก้ไข ไม่ต้องเปลี่ยนชื่อ ดูรายการไฟล์ที่ ไฟล์ที่ต้องวาง

2

ดับเบิลคลิก Run.bat

หน้าต่างสีดำจะแสดงความคืบหน้า รอจนมีกล่องคำถามขึ้นมา ระหว่างนี้ไม่ต้องทำอะไร

3

ตรวจ QC ก่อนตอบคำถาม

กล่องคำถามรอได้ ยังไม่ต้องกด เปิดโฟลเดอร์ output\<วันที่>\<เลขรอบ> แล้วตรวจ:

  • ไฟล์ QC ....txt: ดู CHECKLIST ว่าไฟล์ครบ และดูบรรทัดที่ขึ้นต้นด้วย ALERT, WARNING, CHECK
  • รูปรายงาน .png และไฟล์ workbook: ดูว่าตัวเลขสมเหตุสมผล
4

ตอบคำถาม 2 ข้อ

  • Replace the workbook in Main with this output?
    Yes = ไฟล์ผลลัพธ์กลายเป็นไฟล์หลักของวันถัดไป ไฟล์เดิมถูกเก็บไว้ใน Main\previous
    No = Main อยู่เหมือนเดิม
  • Delete the export file(s) that were used from the Input folder?
    Yes = ไฟล์ที่ใช้แล้วไปอยู่ใน Recycle Bin, Input ว่างพร้อมสำหรับวันถัดไป
    No = ไฟล์อยู่ใน Input ต่อ

ทั้งสองข้อ ค่าเริ่มต้นคือ No กด Yes เมื่อ QC ผ่านแล้วเท่านั้น

5

ส่งรายงาน

ใช้ไฟล์ workbook และรูปจากโฟลเดอร์ output ของรอบนั้น แล้วกดปุ่มใดก็ได้เพื่อปิดหน้าต่างสีดำ

ถ้า QC ไม่ผ่าน ให้ตอบ No ทั้งสองข้อ แก้สาเหตุ (เช่น ดาวน์โหลดไฟล์ที่ขาดมาเพิ่ม) แล้วรัน Run.bat ใหม่ รันซ้ำกี่รอบก็ได้ในวันเดียวกัน แต่ละรอบได้โฟลเดอร์เลขใหม่ (1, 2, 3 ...) ไม่ทับของเดิม

อ่าน QC report

อ่านจากบนลงล่าง: CHECKLIST ของไฟล์, รายละเอียดของแต่ละส่วน, สิ่งที่เปลี่ยนในแต่ละ sheet, แล้วปิดท้ายด้วยตัวเลขรายงานก่อนและหลัง

แต่ละรอบมี QC สองไฟล์ที่เนื้อหาเหมือนกัน: ฉบับอังกฤษ และฉบับไทย (TH) ในฉบับไทย คำขึ้นต้นบรรทัด (OK, MISSING, ALERT ...) ชื่อ sheet ชื่อคอลัมน์ และชื่อไฟล์ ยังเป็นภาษาอังกฤษเหมือนเดิม จึงใช้ตารางด้านล่างได้กับทั้งสองฉบับ หน้าต่างสีดำตอนรันยังแสดงเป็นภาษาอังกฤษ

คำขึ้นต้นความหมายต้องทำอะไร
OKได้รับไฟล์ของส่วนนั้น พร้อมจำนวนแถวไม่ต้องทำอะไร
MISSINGไม่มีไฟล์ของส่วนนั้นใน Inputดาวน์โหลดมาเพิ่ม แล้วรันใหม่
UNKNOWNมีไฟล์ที่โปรแกรมไม่รู้จัก หรืออ่านยี่ห้อไม่ออกตรวจว่าเป็นไฟล์ถูกต้อง หรือใส่ยี่ห้อในชื่อไฟล์
LEFT OUTแถวที่ตั้งใจไม่ใส่ เช่น NETA (เลิกขายแล้ว)ไม่ต้องทำอะไร
ALERTไฟล์ขาด, เดือนของ export ไม่ตรงกับ workbook, หรือมีรถใน Main ที่ไม่อยู่ใน export วันนี้หาสาเหตุก่อนตอบ Yes
WARNINGเลขตัวถังซ้ำใน Main, รถอยู่ผิด sheet, หรือถ่ายรูปไม่สำเร็จตรวจแถวที่ระบุ
CHECKยอดเดือนของสอง sheet ไม่เท่ากัน หรือ showroom / model ไม่มีแถวในรายงาน (ยอดจะไม่ถูกนับ)ตรวจใน workbook
DIFFERENT (not changed)
DIFFERENT (ไม่ได้แก้)		รถที่มีอยู่แล้วใน Main มีค่าต่างจาก export เช่น Status เปลี่ยนเป็น Confirm โปรแกรมไม่แก้ให้ถ้าต้องการค่าใหม่ ให้แก้ใน workbook เอง
ADDEDยอดขายใหม่ที่เพิ่มลง sheet พร้อมเลขแถวดูว่าตรงกับยอดขายของวัน
REMOVEDแถวที่ตัดออกจาก export: แถวรวม/แถวว่าง, เลขตัวถังซ้ำ, order ที่ยกเลิกไม่ต้องทำอะไร
CHANGED / FILLEDค่าที่โปรแกรมแก้ให้ เช่น TUCSON เป็น NEW TUCSON, Pre Date ว่างใช้ BookDate แทนไม่ต้องทำอะไร
TAKEN OUTรถที่ไม่อยู่ในรายงาน (ตุ๊กตุ๊ก) ถูกเอาออกจาก workbookไม่ต้องทำอะไร
NOTEข้อมูลประกอบ เช่น คอลัมน์ที่ export ไม่มี หรือยี่ห้อที่ยังไม่มียอดขายเดือนนี้อ่านผ่าน ๆ ถ้ายี่ห้อนั้นขายได้จริง แปลว่าไฟล์ขาด
